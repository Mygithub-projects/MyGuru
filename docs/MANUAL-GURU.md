# Manual Pengguna — Guru (e-KokoT6)

## 1. Log Masuk
- Gunakan **emel berdaftar** dan kata laluan. Tukar kata laluan lalai pada log masuk pertama.

## 2. Skop Akses
Bergantung pada jawatan kokurikulum anda:
- **Guru Penasihat / Ketua GP / Penolong Ketua GP** — hanya pelajar dalam unit seliaan (Kelab/Sukan/Badan Beruniform yang didaftarkan).
- **Penyelaras / Pemantau (KUPP) / Penolong SU Kokurikulum** — akses seluruh sekolah.

## 3. Dashboard Semakan
Memaparkan item **menunggu tindakan** dalam skop anda:
- **Permohonan Pertukaran Unit** → **Lulus** (kemas kini T6) / **Tolak** (beri sebab).
- **Pencapaian** → masukkan **markah** + **Sahkan**, atau **Kuiri** (minta pembetulan).
- **Aktiviti Luar** → **Sahkan** (markah auto ikut peringkat, e-Cert diaktifkan) / **Kuiri**.
  - Butang *Sahkan* **dilumpuhkan** jika eviden (surat + sijil) tidak lengkap.
- **Laporan Mingguan & Projek** → **Sahkan** / **Kuiri**.
- **Sesi Kehadiran** → **Sahkan** rekod kehadiran ahli.

Setiap tindakan menghantar **notifikasi** kepada pelajar dan mengira semula markah PAJSK T6.

## 4. Analitik
Menu **📊 Lihat Analitik**:
- Kehadiran mengikut unit, status laporan projek, kadar pematuhan laporan mingguan.
- (Skop seluruh sekolah) taburan demografi & jadual silang.
- **Eksport** ke Excel / PDF.

## 5. Prinsip Penting
- **Data T5** ialah rekod sejarah (tidak boleh diubah). **Data T6** ialah data aktif.
- Pengiraan markah PAJSK automatik — tiada pengiraan manual diperlukan.
